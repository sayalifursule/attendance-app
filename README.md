# Attendance Management System

A modern Attendance Management Web Application built using:

- HTML
- CSS
- JavaScript

## Features

- Add Attendance
- Delete Attendance
- Search Students
- Dashboard Analytics
- Local Storage Integration
- Responsive Design
- Glassmorphism UI

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AWS S3
- AWS CodePipeline
- GitHub

## CI/CD Flow

GitHub → AWS CodePipeline → AWS S3
